# Provenance, redistribution, and license boundaries

Pocket God, Pocket God Comics, original characters, logos, printed and digital story pages, and the proprietary iVerse application are third-party intellectual property. The project is **unofficial** and not sponsored by or affiliated with their respective rights holders.

## Included publicly

- Project-authored compatibility bridge source
- Original inspection and QA scripts
- Documentation, architecture, build notes, issue templates
- Verified project observations (with explicit uncertainty)

## Excluded from public distribution

- Original app executable, complete modified IPAs, commercial story pages and printed issues
- Downloaded WEBTOON content and private author archives
- Generated custom cover image files featuring third-party IP
- SDK/toolchain binaries, signing credentials and tokens
- Private device information, personal paths or account access

## Licensing

No explicit open-source license has yet been selected for the project-authored code. Visibility of this repository **does not grant reuse rights**. If a project-code license is chosen later, it must separately address third-party copyrights and trademarks; it cannot license rights the project does not own.

Owning a personal archive does not, on its own, imply permission to distribute it publicly. Use rights-holder-authorized sources and comply with applicable law.

For copyright questions or takedown matters, use GitHub's contact route for the repository owner.

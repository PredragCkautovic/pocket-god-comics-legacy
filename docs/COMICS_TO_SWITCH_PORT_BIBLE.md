# Pocket God Comics — Narrative & Gameplay Reference Bible

**Purpose:** design research for the separate Pocket God Switch port, to use **after** core IPA-based game parity is complete. Comics are an adaptation reference, not proof of mechanics present in any particular Pocket God IPA.

## Source boundaries

- The archive contains **25 original print-issue story reconstructions** from creator-published WEBTOON repost segments, 629 story images; this does not establish exact original print layouts or bonus material.
- Source-of-truth gameplay: each iOS IPA/version and direct hardware capture. Any addition from comics must be classified separately as *comic-derived optional content* and not included in a version-accurate 1:1 port.
- Do not include third-party comic pages, character artwork, proprietary game sprites or sound in a public bible. Preserve provenance/page references privately.

## Candidate extraction schema (for internal per-page review)

Record **issue, page number, story beat, characters, objects, environment, interaction, animation/audio cues, original source reference, confidence**, and proposed game version/timeline. Quote descriptions rather than copying full panels into public docs.

## Integration gates

1. **Original game accuracy first:** finish v1.0→later IPA parity before any comic-origin additions.
2. **Source attribution:** verify each proposal against corresponding comic pages and note print-issue vs WEBTOON chapter numbering.
3. **Design separation:** only add comic events as an optional expansion, toggle, or later creative mode; never silently change source-authentic episodes.
4. **Reuse responsibly:** use only original owned/authorized assets or newly created graphics where redistribution is permitted.
5. **QA:** create separate behavior tests for proposed mechanics, with Switch performance and touch interaction verification.

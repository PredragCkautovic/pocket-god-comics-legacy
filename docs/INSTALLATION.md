# Preparing a legacy device for testing

The public repository does **not** distribute a compiled commercial application, proprietary comic art or iVerse files. Only use an original application copy and offline content you are entitled to possess and use.

## Before installation

1. Back up the original application **and its associated data container**.
2. Check device OS and available space. Full archive packages are large and may need substantial temporary unpacking space.
3. Confirm your archive version is **v13 universal QA**, not the obsolete v11 builds linked to startup crashes.
4. Use a compatible, authorized installation mechanism. Some old device configurations require jailbreak-based installation; this repository doesn't provide signing credentials or instructions for bypassing ownership controls.
5. Note the test package ID and whether it is installed next to another edition or over an existing app.

## On launch

The original initial screen appears first. **Do not expect the library to pop up automatically.** Open *My Comics* manually, then test scrolling, covers, reading, returning to the shelf and reopening the app.

Offline pages already packaged locally should be readable without depending on the old Store servers. That does not revive or emulate old iVerse commerce services.

If a crash occurs, record the device model, precise OS version, action, comic number (if any), and sanitized diagnostics. See [Troubleshooting](TROUBLESHOOTING.md).

## Why are private test builds not here?

Commercial iVerse app and Pocket God comic material are third-party copyrighted content. Public redistribution rights are not established. The open project documents compatibility work without making those assets publicly accessible.

# Contributing

Thank you for helping document and preserve the original reading experience.

Useful contributions include reproducible device reports, original bridge fixes, memory profiling on iOS 7–9, accessibility work and documentation improvements.

## Before opening an issue

Provide the exact device, iOS version, 25/63 edition and repeatable steps. Search existing reports first. Be clear whether you **observed behavior on hardware** or only compiled/inspected an archive.

## Before submitting code

1. Describe the original behavior and how the patch preserves it.
2. Keep changes small and testable.
3. Do not submit any copyrighted commercial IPA, original comics, artwork, SDKs or private files.
4. Do not post credentials, personal paths, private IPs, device keys or unredacted logs.
5. Provide validation results and the list of devices you tested.

A public repository is not automatically an open-source license. No explicit code reuse license has been selected yet.

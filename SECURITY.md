# Security and privacy

This project concerns very old devices and unmaintained commercial app components. Take precautions.

- Never put jailbreak credentials, signing certificates, tokens, SSH keys, passwords or private device data into issues or pull requests.
- Back up your test device and original app container before changes.
- Prefer separate test hardware; do not modify unrelated operating-system settings for this project.
- Do not distribute copyrighted application or comic binaries through public tickets.
- The compatibility bridge is **experimental**, not an audited security-hardened app.

For a privately exploitable vulnerability or an accidentally exposed credential, contact the repository owner through private GitHub channels rather than public discussion.
